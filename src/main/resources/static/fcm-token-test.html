🔔 FCM 토큰 발급기

백엔드 날씨 푸시 테스트용 — FCM 토큰을 발급받아 Postman에서 등록하세요.

값 가져오는 방법:
1. Firebase Console 열기
2. mom-med 프로젝트 선택
3. ⚙️ 프로젝트 설정 → 일반 탭 → 하단 "내 앱" 섹션
   → 웹 앱이 없으면 "앱 추가" → 웹(</>) 으로 하나 생성
   → apiKey, messagingSenderId, appId 복사
4. 클라우드 메시징 탭 → 웹 푸시 인증서
   → 없으면 "생성" → 키 쌍(VAPID Key) 복사
Firebase 웹 앱 설정
프로젝트 설정 → 일반 → 웹 앱 → apiKey
프로젝트 설정 → 일반 → 프로젝트 번호 (숫자)
프로젝트 설정 → 일반 → 웹 앱 → appId
프로젝트 설정 → 클라우드 메시징 → 웹 푸시 인증서 → 키 쌍
